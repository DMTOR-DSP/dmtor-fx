# DMTØR FX

Every effect in the DMTØR lib, from NOEMA, Speak & Grain and RUPTURE: what each one does and what
you can turn. **See it at [dmtor-dsp.github.io/dmtor-fx](https://dmtor-dsp.github.io/dmtor-fx/).**

The page is generated from the lib (`tools/make-fx-page.py` there) and published here with
`tools/publish-fx-page.sh`, so make changes in the lib rather than here.
